## About the Project

StudyDost is a smart learning companion that helps students organize their studies, follow personalized learning paths, manage study materials, and revise faster.

The platform brings essential study tools together in one place, helping students stay focused, track their progress, and make learning more efficient.

## Key Features

- **Personalized Learning Paths:** Structured learning journeys based on student goals.
- **Notes Summarization:** Upload text notes and selectable-text PDFs to generate concise revision summaries locally.
- **Study Materials:** Organize and access learning resources in one place.
- **Progress Tracking:** Monitor study activities and learning progress.
- **Study Assistant:** Get help with common study-related questions through offline rule-based responses.
- **Interactive Dashboard:** Access important learning tools through a student-friendly interface.

## How It Works

1. Open the StudyDost dashboard.
2. Explore your learning tools and study resources.
3. Follow your learning path.
4. Upload notes to generate quick revision summaries.
5. Track your progress and continue learning.

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd StudyDost
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Offline Mode

No API key is required for the current offline mode.

- Text notes and selectable-text PDFs are summarized locally.
- The StudyDost Study Assistant uses rule-based responses.
- No external AI API connection is required for these offline features.
- Scanned PDFs may require OCR support.
