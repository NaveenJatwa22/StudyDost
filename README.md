# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/5d002714-c5c7-42aa-bdbb-6e6cd85c2f2e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. No API key is required for offline mode. Text notes and selectable-text PDFs are summarized locally. The StudyDost AI Helper uses rule-based offline responses.
3. Run the app:
   `npm run dev`
